GRC Policy-as-Code Dashboard

Static GitHub Pages dashboard for policy-as-code learning. Edit the sample JSON and Rego policy in your browser, then run the evaluation locally or deploy the backend separately.

Dashboard workspace

This page is a static front-end. Actual policy evaluation is not available on GitHub Pages. Use the local app or a separate backend service for live results.

Evaluation output

Actual evaluation is only available in the local Flask app or a deployed backend. To run locally: 1. Start the app with python3 app.py 2. Open http://localhost:8080 To deploy a live backend, host the Flask app separately and set the Backend API URL above.

How it works

GitHub Pages serves only static files. The editor experience on this page is client-side only, and it does not execute policy evaluation in the browser.

Local run

To get a working policy-as-code command center, run the app locally in your dev container with:

python3 app.py
